# audio/

`legion.mp3` — trilha de fundo. Origem: Freesound, som **62972**
(`freesound_community-rome-legion-62972.mp3`), 57s, 160kbps.

**Confira a licença antes de publicar o jogo.** Sons do Freesound são CC0,
CC-BY ou CC-BY-NC dependendo do autor. Se for CC-BY, o crédito ao autor
original precisa aparecer em algum lugar visível (tela de menu ou README).
A página do som é `https://freesound.org/s/62972/`.

Este é o único asset externo do projeto — todo o resto (sprites, chão, efeitos
sonoros e a trilha de reserva) é gerado em runtime. Se o arquivo sumir ou o
navegador recusar carregá-lo, `Soundtrack` cai para a trilha procedural em
`js/music.js` e o jogo continua com música.
